# project_1_digitales

Uso de los switches:
SW7, SW6, SW5, SW4 forman A, con pesos 8, 4, 2, 1.
SW3, SW2, SW1, SW0 forman B, con pesos 8, 4, 2, 1.
SW8 = 0: suma. SW8 = 1: resta.

Pruebas para hacer con los switches:
A = 0011, B = 0101, SW8 = 0: LEDs = 00001000 (3 + 5 = 8).
A = 1001, B = 1001, SW8 = 0: LEDs = 00010010 (9 + 9 = 18).
A = 1001, B = 0100, SW8 = 1: LEDs = 00000101 (9 - 4 = 5).
